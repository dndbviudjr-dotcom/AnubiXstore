# AnubiXstore - Mini Site de Jogos

Um site minimalista e elegante para gerenciar sua coleção de jogos com amigos!

## Características

- **Design Preto Minimalista**: Interface elegante e clean em tema escuro
- **Vídeo de Fundo**: Suporte para video.mp4 como fundo dinâmico
- **Animações Fluidas**: Cards com efeitos de hover e transições suaves
- **Transparências**: Glassmorphism com backdrop-filter para visual premium
- **Responsive**: Funciona em desktop, tablet e mobile
- **Armazenamento Local**: Dados salvos automaticamente no localStorage
- **Foto/Capa**: Suporte para adicionar imagens para cada jogo
- **Download**: Botão para abrir o link de download do jogo
- **Sem Emojis**: Design clean e profissional

## Como Usar

### 1. Preparar o Vídeo de Fundo

Coloque um arquivo chamado `video.mp4` na mesma pasta do site. O vídeo pode ser:
- Qualquer vídeo em formato MP4
- Será reproduzido em loop, sem som
- Recomenda-se: 1080p ou 1440p para melhor qualidade
- Tamanho: quanto menor, melhor (use compressão se necessário)

**Dica**: Você pode usar sites como:
- Pexels Videos (https://www.pexels.com/videos/)
- Pixabay (https://pixabay.com/videos/)
- Ou gravar seu próprio vídeo

### 2. Adicionar Jogos

1. Abra `index.html` em um navegador
2. Clique no botão "Adicionar Jogo"
3. Preencha:
   - **Nome do Jogo**: Título/nome do jogo
   - **URL de Download**: Link para download (Steam, Epic, etc)
   - **Foto/Capa**: URL da imagem do jogo
   - **Descrição**: Breve descrição (opcional)
4. Clique "Salvar Jogo"

## Exemplos de URLs

- Steam: `https://store.steampowered.com/app/570590/Cyberpunk_2077/`
- Epic Games: `https://www.epicgames.com/store/en-US/p/fortnite`
- GOG: `https://www.gog.com/`
